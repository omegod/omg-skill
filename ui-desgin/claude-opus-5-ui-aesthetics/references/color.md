# 色彩

## 为什么用 OKLCH

`oklch(L C H)` 感知均匀：L 相同则视觉明度相同。改 H 不影响明暗，改 L 步长一致，这两点 HSL 都做不到（HSL 里 `hsl(60,100%,50%)` 黄和 `hsl(240,100%,50%)` 蓝的实际明度差 6 倍）。所有色阶用 OKLCH 定义，再转 hex 落地。

CSS 可直接写 `oklch(0.62 0.16 264)`，现代浏览器全支持。需兼容旧环境时用 `scripts/palette.py ramp` 导出 hex。

## 三层结构

```
中性色 (neutral)   承担 90% 画面：背景、表面、边框、文字
强调色 (accent)    承担 5%：主按钮、链接、选中态、焦点环、数据高亮
语义色 (semantic)  承担 5%：success / warning / danger / info
```

**中性色必须带 tint**：中性色相取 accent 色相，chroma 0.002–0.012。纯灰（C=0）配彩色 accent 会显脏、显廉价，画面不"整"。tint 量：奢侈/极简 0.002–0.004，通用 0.005–0.008，消费/温暖 0.008–0.012。

## 彩度预算（按涂色面积）

| 角色 | 面积 | C 上限 | 例 |
|---|---|---|---|
| `page` | 全屏底 | 0.012 | 页面背景 |
| `surface` | 大块 | 0.020 | 卡片、面板、侧栏 |
| `block` | 中块 | 0.060 | 高亮行、tag 底、提示条底 |
| `control` | 小块 | 0.190 | 按钮填充、开关、进度条 |
| `detail` | 极小 | 0.300 | 图标、徽标、圆点、图表描边 |

这条是"高级 vs 廉价"的最大分水岭。大面积高彩度＝儿童软件观感。

## 色阶

11 级：`50 100 200 300 400 500 600 700 800 900 950`。用途固定：

| 级 | 浅色模式用途 | 深色模式用途 |
|---|---|---|
| 50/100 | 页底、hover 底、选中底 | — |
| 200/300 | 边框、分隔线、禁用底 | — |
| 400/500 | 占位符、图标、次要文字（≤0.65L） | 边框、次要文字 |
| 600/700 | 主按钮填充、链接、正文强调 | 主按钮填充、链接 |
| 800/900/950 | 正文、标题 | 页底、表面 |

深色模式不是把色阶倒序用，见下节。

## 强调色填充

**关键实测结论：accent 填充配白字，L 上限 0.57，且与彩度无关**（C=0.10 → 0.57，C=0.19 → 0.576）。亮度是对比度的唯一杠杆。

- 主按钮：`L 0.52–0.57`，配 `#fff`。想更醒目→加 C，不要提 L。
- hover：L −0.04（变深），不是变浅
- active：L −0.07
- 深色模式 accent：L 提到 **0.68–0.72**，C 降 15–25%（暗底上高彩度会"振动"）。L0.70/C0.13 对暗底 7.03:1。
- 浅色底上的 accent 文字/链接：L ≤ 0.55
- 焦点环：需对底 3:1 → 浅色底下 **L ≤ 0.65**

## 语义色

色相固定，别自创：

| 语义 | H | 说明 |
|---|---|---|
| success | 150 | 偏青绿比黄绿更"贵" |
| warning | 70 | 纯黄配白字永远不合格，必须配深色字 |
| danger | 27 | 与红色系 accent 冲突时，danger 移到 15–20 |
| info | 245 | 与蓝色 accent 冲突时直接复用 accent |

**永不只靠颜色传达状态**：色 + 图标 + 文案三者齐备（8% 男性红绿色盲）。

浅底提示条配方：底 = 语义色 50（C≤0.06），边框 = 200，图标 = 600，文字 = 900。

## 阴影颜色

黑色半透明阴影会让画面发灰。阴影应取**主色相的深色版**：

```css
--shadow-color: 264 8% 22%;               /* H S L，跟随 accent 色相 */
box-shadow: 0 1px 2px hsl(var(--shadow-color) / 0.06),
            0 4px 12px hsl(var(--shadow-color) / 0.05);
```

两层叠加：一层紧贴（1–2px，定义边缘），一层扩散（8–24px，定义高度）。单层阴影永远假。

## 渐变：唯一正确用法

AI 界面最大的"味源"。**默认不用渐变。** 确实要用时只有三种合法情况：

1. **同色相微渐变**：H 相同，L 差 ≤0.08，C 差 ≤0.03。用于按钮/卡片的极轻立体感。
2. **图片蒙版**：图上叠文字时的黑色渐变遮罩（`to top, rgb(0 0 0 /.7), transparent`）。
3. **数据可视化**：面积图填充、热力图。

绝对禁止：紫→蓝（`#667eea→#764ba2` 这类）、跨 ≥60° 色相的双色渐变、渐变文字、彩虹渐变、渐变边框。跨色相渐变中段必然出现浑浊灰带（OKLCH 插值可缓解，但仍显廉价）。

## 校验

```bash
# 单色检查
python3 scripts/palette.py info "#436ed1" "oklch(0.62 0.16 264)"

# 逐对校验
python3 scripts/palette.py check --pair "#727477" "#f9fafd" 4.5 \
                                  --pair "#ffffff" "#436ed1" 4.5

# 整套 token 校验（含彩度预算）
python3 scripts/palette.py check --tokens my-tokens.json
```

`my-tokens.json`：
```json
{
  "pairs": [{"fg": "#1e1f22", "bg": "#f9fafd", "min": 4.5, "label": "body"}],
  "areas": [{"role": "page", "color": "#f9fafd"},
            {"role": "control", "color": "#436ed1"}]
}
```
