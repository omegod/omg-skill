# 布局

## 内容宽度

| 类型 | 宽度 | 说明 |
|---|---|---|
| 正文阅读 | 62–72 字符（≈640–720px） | 中文 34–40 字/行 |
| 表单单列 | 400–560px | 再宽视线扫描成本剧增 |
| 应用主体 | 1200 / 1280 / 1440 上限 | 超宽屏留白，别拉满 |
| 营销页 | 内容 1120–1280，视觉块可通栏 | |
| 数据表格 | 可通栏 | 但需固定首列 |

**永远不要 100% 宽度铺满 2560px 屏**。设 `max-width` + `margin-inline:auto`。

## 栅格

12 列。gutter 跟随密度：紧凑 16px，通用 24px，疏朗 32px。
外边距 ≥ gutter × 1.5。

组合规律：
- 内容+侧栏 = 8+4 或 9+3
- 三卡片 = 4+4+4
- 图文对开 = 6+6（图片侧可出血）

## 页面骨架尺寸

| 元素 | 紧凑 | 通用 | 疏朗/营销 |
|---|---|---|---|
| 顶栏高 | 48–56 | 56–64 | 72–80 |
| 侧栏宽 | 200–240 | 240–280 | — |
| 侧栏收起 | 48–56 | 56–64 | — |
| 内容区 padding | 16–20 | 24–32 | 48–64 |

## 垂直节奏（营销/落地页）

区块间距是落地页高级感的核心变量：

```
Hero 上下       96–160px
主要区块间      80–120px
区块内组间      32–48px
组内           8–16px
```

移动端整体 ×0.6（96→64，128→80）。

**区块交替**：连续区块背景在 `page` / `surface` / 深色块之间交替，避免整页一个底色导致的"长条感"。但交替 ≤3 种底色。

## 响应式

断点（内容驱动，非设备驱动）：
```
sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536
```

**断点处改结构，不只是等比缩放**：
- 侧栏 → 底部 tab 或抽屉（<1024）
- 多列 → 单列（<768）
- 表格 → 卡片列表（<768）
- 横向 tab → 下拉选择（<640）

字号：display 类移动端降 20–30%（60→40），body **不降**（16 就是 16，降到 14 会难读）。iOS 上输入框 `font-size` <16px 会触发自动缩放，务必 ≥16px。

间距：移动端垂直间距 ×0.6，水平 padding 最小 16px。

## 触控与目标尺寸

- 触摸目标 ≥44×44（可视元素可小，扩大点击区用 padding 或伪元素）
- 鼠标目标 ≥32×32
- 相邻可点元素间距 ≥8px

## 层级 z-index

固定分层，不要随手写数字：
```
base 0 · sticky 100 · dropdown 200 · overlay 300 · modal 400 · toast 500 · tooltip 600
```

## 对齐

整屏 2–3 条垂直对齐轴。检查方法：想象一条竖线穿过页面，所有文字左缘应落在少数几条线上。
卡片内标题、正文、按钮左缘必须对齐；图标与文字**基线对齐**而非居中对齐（图标视觉重心偏上）。
数字右对齐 + `tabular-nums`；文本左对齐。**界面中永不使用两端对齐**（会产生河流状空隙）。居中只用于短标题、空态、营销 Hero——正文和表单绝不居中。
