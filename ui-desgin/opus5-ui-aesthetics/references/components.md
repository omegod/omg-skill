# 组件规格

## 通用状态要求

每个交互元素必须有五态，缺一即返工：

| 态 | 做法 |
|---|---|
| default | — |
| hover | 背景 L −0.03（浅色）/ +0.03（深色）。**不要**改尺寸/位移 |
| focus-visible | 2px accent 环 + 2px 底色 offset。对底 ≥3:1 |
| active | 背景 L −0.06；可加 `scale(.98)`，时长 ≤100ms |
| disabled | `opacity:.45` + `cursor:not-allowed`；保持色彩关系，不要换成灰色 |

`:focus-visible` 而非 `:focus`（避免鼠标点击也出环）。禁止 `outline:none` 后不补。

## 按钮

| 尺寸 | 高 | 水平 padding | 字号 |
|---|---|---|---|
| xs | 28 | 10 | 12 |
| sm | 32 | 12 | 13 |
| md | 36–40 | 16 | 14 |
| lg | 44–48 | 20 | 15 |
| 营销 CTA | 48–56 | 24–32 | 16 |

- 水平 padding ≈ 高度 × 0.4–0.5；图标按钮做正方形
- 字重 500–600，**不要 700**
- 图标与文字间距 6–8px，图标尺寸 = 字号 × 1.15
- 层级：primary（accent 填充）1 个 / secondary（描边或浅底）/ ghost（无底，hover 才有底）/ danger
- **一个视觉区域只能有一个 primary**
- 加载态：替换文字为 spinner 时**锁定按钮宽度**，否则布局跳动

## 输入框

- 高度与同级按钮一致（对齐关键）：md 36–40
- 内边距 12px，字号 14–15（移动端 ≥16 防缩放）
- 边框 1px `--border`，focus 时 `--accent` + 2px 环
- **label 在上方**，12–13px / 字重 500，与输入框间距 6px
- placeholder 只写示例格式（`如：138····8888`），**不能替代 label**
- 帮助文字 12px muted，在下方 4px
- 错误态：边框 danger + 下方 danger 文字 + 图标，三者齐备。错误文字**说明怎么改**（"密码需 8 位以上"）而非"输入无效"
- 必填标记用 `*` 或"（必填）"，不要只靠颜色

## 表格

| 密度 | 行高 | 单元 padding |
|---|---|---|
| 紧凑 | 32–36 | 8×12 |
| 通用 | 40–44 | 12×16 |
| 疏朗 | 48–56 | 16×20 |

- 表头：12px 大写 +0.06em 字距 字重 600，或 13px 常规大小写字重 600。背景 `--sunken`，`position:sticky`
- **斑马纹与横线二选一**，不可同时。行数 >10 用斑马纹，否则用 1px 横线
- 数字右对齐 + `tabular-nums`；文本左对齐；操作列右对齐
- hover 整行背景 L −0.02
- 列宽：内容驱动，关键列固定，长文本列 `text-overflow:ellipsis` + title
- 移动端 <768 转卡片列表，不要横向滚动
- 排序图标常驻占位（否则 hover 时列宽跳动）

## 卡片

- padding：紧凑 16、通用 20–24、疏朗 32
- 圆角取 token 中档；阴影 0 或 1 级
- **边框 / 阴影 / 背景色差三选一**
- 标题 15–16px 字重 600，与内容间距 8–12
- 卡片间距 ≥ 卡片内 padding（否则分不清边界）
- 可点击卡片：hover 时背景变化或阴影升一级，**不要同时缩放+抬升+变色**

## 导航

- 侧栏项：高 36–40，水平 padding 12，圆角 6–8，图标 18–20
- 选中态：accent-subtle 底 + accent 文字/图标；或左侧 2–3px accent 条
- 分组标题：11–12px 大写 muted，上间距 16 下间距 4
- 面包屑：13px，分隔符用 `/` 或 `›`，末项不可点且颜色更深
- Tab：下划线 2px accent，未选中 muted；下划线与文字间距 8–10

## 空态

```
图标/插图 40–64px（muted 色，不要用彩色 emoji）
  ↓ 16
标题 15–16px 字重 600
  ↓ 8
说明 13–14px muted，≤2 行
  ↓ 20
一个主操作按钮
```
容器上下 padding 48–80。文案说明**下一步做什么**，不要只说"暂无数据"。

## 加载态

- 首屏：skeleton（按真实内容形状，圆角与内容一致，动画 1.5s 呼吸）
- 局部：spinner 16–20px
- 按钮内：锁宽换 spinner
- **禁止**整页 spinner 遮罩；禁止 skeleton 和 spinner 同时出现
- 超过 3s 给进度提示或文案

## 弹窗

- 宽度：小 400 / 中 520–560 / 大 720，`max-width:calc(100vw - 32px)`
- 遮罩 `rgb(0 0 0 / .4)`，可加 `backdrop-filter: blur(2px)`（**仅此处**）
- 入场 200–260ms：opacity 0→1 + scale .96→1 或 translateY 8px→0
- 标题 17–18px 字重 600；操作区右对齐，主按钮在右（Windows 习惯）
- 必须支持 Esc 关闭、点遮罩关闭（破坏性操作除外）、焦点陷阱、打开时 `body` 锁滚动
- `role="dialog"` + `aria-modal="true"` + `aria-labelledby`

## 提示条 / Toast

- 提示条：左侧 3px 语义色条或语义图标 + 浅语义底（C≤0.06）+ 深语义文字
- Toast：右上或底部居中，宽 320–420，停留 4–6s，可手动关闭
- 图标 + 颜色 + 文案三者齐备
- 同时最多 3 条，超出排队

## 图表

配色、坐标轴、图例等一律遵循 `dataviz` skill；此处只补两条接口约定：
- 图表色板必须从本 UI 的中性色/accent 体系派生，不得引入第三套色
- 图表内文字字号 ≤ 界面 body 字号 −1
