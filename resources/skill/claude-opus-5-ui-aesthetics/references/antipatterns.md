# 反模式：AI 味清单

产出后逐条自查。这些不是风格偏好问题，是**可识别的生成痕迹**。

## 色彩类

| ❌ 症状 | 为什么廉价 | ✅ 替代 |
|---|---|---|
| 紫→蓝渐变（`#667eea→#764ba2`、`#8b5cf6→#6366f1`） | 最强 AI 标志色，Bootstrap 时代遗产 | 单色平涂；非要渐变则同色相 L 差 ≤0.08 |
| 大面积高彩度背景 | 违反面积–彩度反比 | 背景 C ≤0.012，彩度留给小元素 |
| 纯灰 `#808080` 配彩色 accent | 灰与主色不同源，画面发脏 | 中性色带 tint（C 0.002–0.012，色相同 accent） |
| 满屏都是强调色 | 全部强调＝没有强调 | 整屏一个 accent 焦点 |
| 纯黑背景 `#000` + 纯白字 `#fff` | 对比过载，长时间刺眼 | 底 L 0.16–0.20，字 L ≤0.95 |
| 彩虹色 / 多彩渐变边框 / 渐变文字 | 装饰压过内容 | 删除 |
| 只用颜色区分状态 | 8% 男性红绿色盲不可读 | 色 + 图标 + 文案 |

## 形状与质感类

| ❌ 症状 | ✅ 替代 |
|---|---|
| 所有元素都 `border-radius: 12px`（含按钮、输入、卡片、图片） | 3 档圆角，嵌套用 `外 − padding` |
| 全胶囊化（按钮、卡片都 999px） | 胶囊只给 tag / avatar / 开关 |
| 边框 + 阴影 + 背景色差同时上 | 三选一 |
| 单层大阴影 `0 10px 30px rgba(0,0,0,.3)` | 双层、透明度 ≤0.12、阴影带主色相 |
| 玻璃拟态糊全站（`backdrop-filter` 到处用） | 仅弹窗遮罩、悬浮工具栏；且背后必须有内容 |
| 发光 / 霓虹 / 外阴影光晕 | 删除，除非游戏或音乐场景 |
| 卡片套卡片套卡片 | 最多两层；内层改用间距或分隔线 |

## 排版类

| ❌ 症状 | ✅ 替代 |
|---|---|
| 一页 8+ 种字号 | ≤5 种 |
| 靠 `font-weight:700/800` 撑层级 | 优先字号和颜色，字重 ≤600 |
| 大标题不收字距 | ≥24px 收 −0.02em，≥48px 收 −0.03em |
| 全大写不加字距 | 加 +0.06 ~ +0.1em |
| 正文居中 / 两端对齐 | 左对齐；居中只给短标题、空态、Hero |
| 行宽拉满屏（>100 字符） | 62–72 字符（中文 34–40 字） |
| 中文栈缺失回退宋体 | 字体栈带 `PingFang SC` / `Microsoft YaHei` |
| 数字不等宽，表格里跳动 | `font-variant-numeric: tabular-nums` |

## 布局类

| ❌ 症状 | ✅ 替代 |
|---|---|
| 间距随手写 5/7/13/18/25 | 只用 4px 阶梯 |
| 所有间距都一样（如全 16px） | 分组层级，相邻档比值 ≥1.5 |
| 内容 100% 铺满超宽屏 | `max-width` + 居中 |
| 卡片网格无限堆砌，无层级 | 主次分区，重要内容占更大栅格 |
| 文字左缘七零八落 | 2–3 条对齐轴 |
| 图标与文字中线对齐 | 基线对齐；图标尺寸 = 字号 ×1.15 |
| 落地页区块间距 24px | 区块间 ≥96px |

## 内容与交互类

| ❌ 症状 | ✅ 替代 |
|---|---|
| 彩色 emoji 当图标（🚀✨💡🎉） | 线性图标库（Lucide / Heroicons / Phosphor），统一线宽 |
| Lorem ipsum 或"标题一/内容内容" | 真实合理的业务文案 |
| 三个并列 primary 按钮 | 一个 primary，其余 secondary / ghost |
| placeholder 当 label 用 | label 常驻上方 |
| `outline:none` 后不补焦点样式 | `:focus-visible` 2px 环，对底 ≥3:1 |
| 只做了默认态 | 五态齐全（见 components.md） |
| 没有空态/加载态/错误态 | 三态必做 |
| 错误提示写"输入无效" | 说明怎么改 |
| 文字直接压在图片上 | 加渐变遮罩或半透明层，确保 4.5:1 |
| 悬停就放大 `scale(1.05)` + 变色 + 抬阴影 | 只改一个属性 |
| 动画 500ms+ / 到处弹跳 | 按距离定时长（120–400ms），弹性只给正反馈 |
| 无 `prefers-reduced-motion` | 必须处理 |

## "看起来是 AI 做的"综合症

同时出现 ≥3 条即整体返工：

1. 紫蓝渐变 Hero + 白色圆角卡片 + 大阴影
2. 三列等宽卡片，每张一个 emoji + 标题 + 两行说明
3. 所有圆角 12px，所有间距 16px 或 24px
4. 满屏 `box-shadow: 0 4px 6px rgba(0,0,0,.1)`
5. 玻璃拟态导航栏悬浮在渐变背景上
6. 居中对齐的一切
7. 没有真实内容，全是占位

## 反向检验

问自己：**把颜色全部去掉变成灰度，层级还清晰吗？**
如果不清晰，说明层级是靠颜色撑的，而非靠尺寸、间距和位置——这是最根本的设计缺陷，加多少装饰都救不回来。

第二问：**删掉所有阴影、渐变、圆角，还剩下什么？**
剩下的排版和间距就是设计的真实水平。
