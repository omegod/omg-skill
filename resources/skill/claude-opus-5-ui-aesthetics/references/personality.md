# 场景人格预设

先按业务场景选预设，再按需微调四轴。**不要从零手搓**。
四轴 = 密度 / 彩度 / 柔和 / 重量，各 1–5 分（见 SKILL.md §2.1）。

---

## 1. 企业后台 · SaaS 控制台

`密度4 彩度2 柔和2 重量3` — 参照 Linear、Vercel、Stripe Dashboard

| token | 值 |
|---|---|
| body / ratio | 14px / 1.2 |
| 间距倍率 | 0.85×（内 12、组 16、区块 32） |
| 圆角 | 4 / 6 / 8 |
| accent C | 0.13–0.16 |
| 中性 tint | 0.005 |
| 字重 | 400 / 500 / 600 |
| 阴影 | 0–1 级为主 |
| 控件高 | 32–36 |

要点：信息密度优先，靠 1px 边框和 `--sunken` 底分区，几乎不用阴影。侧栏 240，顶栏 56。表格是主角。深色模式必备。

## 2. 数据分析 · 监控 · BI

`密度5 彩度2 柔和1 重量2` — 参照 Grafana、Datadog、Observable

| token | 值 |
|---|---|
| body / ratio | 13px / 1.125 |
| 间距倍率 | 0.75×（内 8–12、组 12、区块 24） |
| 圆角 | 2 / 4 / 6 |
| accent C | 0.14 |
| 中性 tint | 0.004 |
| 控件高 | 28–32 |

要点：**默认深色模式**（长时间盯屏）。图表是主角，UI 必须退让——边框极淡、无阴影、无装饰。数字全部 `tabular-nums`。图表色板从 accent 派生。

## 3. 消费级 App · 社交 · 工具类前台

| token | 值 |
|---|---|
| body / ratio | 15–16px / 1.25 |
| 间距倍率 | 1.0×（内 16、组 24、区块 48） |
| 圆角 | 8 / 12 / 16 |
| accent C | 0.17–0.19 |

## 4. 营销落地页 · 官网首页

`密度1 彩度3 柔和3 重量4` — 参照 Apple、Framer、Raycast 官网

| token | 值 |
|---|---|
| body / ratio | 16–17px / 1.25 + display 跳档 |
| display | 48 / 60 / 72（移动端 ×0.7） |
| 间距倍率 | 1.5×（区块间 96–128） |
| 圆角 | 8 / 12 / 16 |
| accent C | 0.16 |
| 字重 | 400 / 500 / 600（display 可 600–700） |
| 控件高 | CTA 48–56 |

要点：**留白就是设计**，区块间距 ≥96 是高级感来源。首屏一句话说清价值 + 一个 CTA。display 字号必须收字距 −0.03em。区块背景交替（page/surface/深色块）打破长条感。图片是主视觉——宁可用高质量占位图，也别用彩色 emoji 撑场。

## 5. 内容阅读 · 文档 · 博客

`密度2 彩度1 柔和2 重量2` — 参照 Stripe Docs、Medium、Substack

| token | 值 |
|---|---|
| body / ratio | 17–18px / 1.333 |
| 行高 | 1.65–1.75 |
| 内容宽 | 640–720px（中文 34–40 字/行） |
| 间距倍率 | 1.25× |
| 圆角 | 4 / 8 |
| accent C | 0.12–0.14 |
| 中性 tint | 0.004 |

要点：可读性压倒一切。段间距 = 行高 × 1.2。标题上间距 ≈ 下间距 × 2.5（标题属于下文）。代码块用 `--sunken` 底 + 等宽字体。链接用 accent + 下划线（`text-underline-offset:2px`）。目录固定右侧或左侧。

## 6. 电商 · 商品列表与详情

`密度4 彩度3 柔和3 重量3` — 参照 Shopify 店铺、Uniqlo

| token | 值 |
|---|---|
| body / ratio | 14–15px / 1.2 |
| 间距倍率 | 0.85–1.0× |
| 圆角 | 4 / 8（图片同卡片圆角） |
| accent C | 0.17（转化色） |
| danger/促销 | H 27，C 0.18 |

要点：**商品图是主角**，卡片必须极简（无边框无阴影，靠间距分隔）。图片统一宽高比 `object-fit:cover`。价格是全页最强文字层级之一（16–20px 字重 600）。促销色与 accent 必须区分。加购按钮全站位置固定。

## 7. 开发者工具 · CLI 文档 · API 平台

`密度4 彩度2 柔和1 重量2` — 参照 GitHub、Vercel、Railway

| token | 值 |
|---|---|
| body / ratio | 14px / 1.2 |
| 等宽字号 | 13px |
| 间距倍率 | 0.85× |
| 圆角 | 4 / 6 |
| accent C | 0.14 |
| 中性 tint | 0.004 |

要点：等宽字体是一等公民（`ui-monospace, SFMono-Regular, "JetBrains Mono", Menlo, Consolas, monospace`）。代码块需一键复制。深色模式必备且要精修语法高亮。避免任何装饰性元素。

## 8. 奢侈品 · 时尚 · 高端品牌

`密度1 彩度1 柔和1 重量2` — 参照 Aesop、COS、Hermès

| token | 值 |
|---|---|
| body / ratio | 15–16px / 1.333 |
| 间距倍率 | 1.5×+（区块 128–200） |
| 圆角 | **0**（或 ≤2） |
| accent C | 0.02–0.06（近乎无色） |
| 中性 tint | 0.002 |
| 字重 | 300–400 / 500 |
| 阴影 | **none** |
| 标签 | 11px 大写 +0.1em 字距 |

要点：近乎单色，极限留白，**零圆角零阴影**。全大写小字号 + 大字距做标签。图片通栏出血。字重偏轻（300–400）。任何"科技感"元素（渐变、发光、玻璃拟态）都会毁掉这个人格。

## 快速选择

| 用户说 | 选 |
|---|---|
| 后台 / 管理系统 / 控制台 | 1 |
| 仪表盘 / 监控 / 报表 / 大屏 | 2 |
| App / 小程序 / 用户端 | 3 |
| 官网 / 首页 / 落地页 / 推广页 | 4 |
| 文档 / 博客 / 知识库 | 5 |
| 商城 / 商品 / 下单 | 6 |
| 开发者 / API / 技术产品 | 7 |
| 品牌 / 高端 / 质感 / 极简 | 8 |

**混合场景**：按主要页面选，局部借用。如"SaaS 官网 + 后台"= 官网用 4、后台用 1，但**共用同一套色彩 token**保证品牌一致。

用户给了品牌色 → 取其 OKLCH 色相灌进 `palette.py ramp --hue`，其余按预设走。
用户没给 → 蓝 264（稳）、青绿 175（清爽）、暖橙 45（友好）、深绿 155（金融/健康）。**避开 270–290 紫**，那是 AI 生成界面的标志色。
